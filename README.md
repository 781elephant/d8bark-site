# D8 Bark launch site

Static site built for GitHub Pages and d8bark.com.

## Launch

1. Upload every file and folder in this directory to the root of your GitHub repository.
2. In GitHub Pages, publish from the main branch and root folder.
3. Keep the included CNAME file if d8bark.com will point to this site.
4. Update DNS to GitHub Pages using your domain provider.

## Order routing

Open `config.js`.

`orderEmail` is currently set to `orders@d8bark.com`.

To enable WhatsApp ordering, add the full WhatsApp number in international format with digits only, for example `9715XXXXXXXX`.

When a WhatsApp number is present, order requests open WhatsApp with the full build and customer details. Without it, requests open the customer email app addressed to the order email.
